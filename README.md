# Portafolio de Héctor Suárez Valadez

Versión sin Node.js, React ni npm.

## Cómo abrirlo
1. Descomprime la carpeta.
2. Abre `index.html` con Chrome, Edge o Firefox.
3. No necesitas instalar nada.

## Editar
- `index.html`: contenido principal.
- `css/styles.css`: diseño visual.
- `js/main.js`: idioma ES/EN, menú y animaciones.
- `projects/`: páginas de cada proyecto.
- `images/`: fotografías.

## Importante
En `index.html`, reemplaza:
`mailto:tu-correo@ejemplo.com`
por tu correo público real cuando decidas cuál usar.

Las páginas de proyectos están creadas como estructura inicial y se completarán conforme desarrollemos cada proyecto.
